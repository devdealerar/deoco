# Componentes de Untitled UI PRO resueltos con uno propio

La versión gratuita de Untitled UI no trae estos componentes. Cada uno se resolvió con uno
propio en `@/ui` (`src/ui/`). Si algún día se compra PRO, se pueden reemplazar sin tocar las
pantallas (todas importan de `@/ui`).

| `@/ui` | Componente PRO que reemplaza | Dónde se usa |
| --- | --- | --- |
| `Aviso` | `application/alerts` | Panel: dominio que dejó de apuntar al servidor |
| `Tarjeta` | (no hay tarjeta en la gratuita) | Varias pantallas del panel |
